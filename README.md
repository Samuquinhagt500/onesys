# OneSys ERP - Gestão para Construção Civil

Sistema de gestão integrado (ERP) desenvolvido em Electron e Node.js, focado em pequenas e médias construtoras.

## 🚀 Funcionalidades Principais

* **Gestão de Obras:** Controle de canteiro, engenheiros e mestres responsáveis.
* **RH Completo:** Cadastro de funcionários, cálculo de folha, controle de ponto e dossiê jurídico.
* **Financeiro:** Controle de caixa (Entradas/Saídas) com categorias e centros de custo.
* **Almoxarifado:** Controle de estoque de materiais.
* **Segurança:** Login criptografado e níveis de acesso (Admin, Mestre, Engenheiro).

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3 (Neon Design), JavaScript Puro.
* **Backend:** Node.js (Electron Main Process).
* **Banco de Dados:** PostgreSQL (via Supabase).

## 📦 Como Rodar o Projeto

1.  Instale as dependências:
    ```bash
    npm install
    ```

2.  Inicie o sistema:
    ```bash
    npm start
    ```
